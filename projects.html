Projects

RP2040 DevBoard

This project is a simple development board based around the RP2040 microcontroller. It was designed by Blake Mangum to give our club an easy and reliable board for learning. This board will definitely be used during most of our club meetings, giving members a simple way to get started with microcontrollers.

Webtroller

This project was designed by one of our members, Espen North, to control a game using visual input. As demonstrated in the video, the project allows users to interact with the game through simple hand movements and gestures, turning natural motion into in-game controls.

Hyperion Macropad

This project was made again by Blake Mangum to help use different applications more efficiently by making all of the shortcuts accessible from a single input. All of it wraped up in a custom case to elevate part of the pad to make it more accessible and easier to use.

We are always building new and exciting projects! be sure to check back here often to see our latest work.
